# Request letter after inspection (for the buyer's agent to send)

Rule for every line: it must be (1) a hazard the inspector flagged, (2) work that needs a licensed trade, (3) a document that costs the seller nothing, or (4) access for a test the buyer pays for. End-of-life items belong in price, not in this letter.

```
Hi [agent name],

We are not sending a long repair list. This is the short one, and it is the one
that decides whether we move forward.

Before closing, at the seller's cost, with licensed receipts:
  1. [Hazard, report page N, in the inspector's words]
  2. [Hazard, report page N]
  3. [Pest: prior treatment records, or treatment before closing by a licensed
     company with a transferable warranty]

A credit of $[amount] for [the one item: what it is, report page, and that it
needs a licensed contractor and a permit].

Documents, at no cost to the seller: [the property condition disclosure or
confirmation of an exemption], [the lead paint disclosure for pre-1978 homes],
[prior treatment records], [permits or sign-offs for finished areas].

Access for two tests we pay for: a sewer line camera scope and an oil tank
sweep.

That is the whole list. It comes to about [X] percent of the price, [which is
below what is customary, if true]. We can move quickly if the seller is comfortable with it. If
not, we understand, and we will step aside.

Best,
[names]
```

Only keep the last sentence if it is true.
